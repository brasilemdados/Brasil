# 🇧🇷 Brasil em Dados

**Um projeto de brasileiros para brasileiros.**

O Brasil em Dados não existe para dizer o que pensar sobre o Brasil, existe para tornar mais fácil encontrar os dados necessários para entendê-lo.

## Eixos temáticos
Esses eixos orientam as perguntas, análises e conjuntos de dados desenvolvidos pelo projeto. O projeto concentra suas análises nos seguintes eixos temáticos:

* Saúde;
* Educação;
* Cultura;
* Moradia;
* Segurança;
* Alimentação;
* Trabalho;
* Lazer;
* Transporte;
* Previdência Social;
* Assistência aos desamparados;
* Proteção à maternidade e à infância;
* Renda Básica Familiar;
* Meio Ambiente Ecologicamente Equilibrado;
* Livre Exercício dos Cultos Religiosos;
* Privacidade Digital e Proteção de Dados;
* Acesso à Justiça.

## Princípios

O projeto é orientado por quatro princípios fundamentais.

### 1. Todos são bem-vindos

Qualquer pessoa pode utilizar, estudar, discutir e contribuir com o projeto. Não importa sua formação, profissão, região, experiência técnica, religião ou visão de mundo. As contribuições são avaliadas com base na qualidade dos dados, rastreabilidade, metodologia e aderência aos padrões do projeto.

### 2. O projeto é apartidário e agnóstico

O Brasil em Dados não representa partidos políticos, governos, candidatos ou grupos de interesse. O projeto não existe para defender uma interpretação específica da realidade brasileira.

Sempre que possível, os dados devem ser apresentados de forma que sua origem, metodologia e limitações possam ser verificadas de maneira independente.

### 3. Compartilhamos fatos, não juízos de valor

O Brasil em Dados apresenta **dados, fontes e contexto metodológico**.

Não atribuímos aos números conclusões políticas, morais ou ideológicas.

O que **NÃO** fazemos aqui:
 - A gestão foi boa porque o indicador aumentou.
 - O estado está melhor ou pior por causa desse número.

O que o projeto é focado em fazer:
  - A população do município variou X% entre os anos A e B.
  - Segundo a fonte X, o indicador apresentou o valor Y no período Z.

Atenção: Se a variação da população ter variado X% é bom ou ruim deve ser uma conclusão do usuário. Ou seja, **a interpretação pertence a quem utiliza os dados.**

### 4. O projeto deve ser compreensível

O Brasil em Dados deve poder ser compreendido pelo maior número possível de pessoas.

Por isso, o código, a documentação, os nomes de arquivos, variáveis, funções, comentários e demais elementos produzidos pelo projeto devem, sempre que possível, ser escritos em **língua portuguesa padrão**.

Devemos preferir palavras simples, claras e comuns no português brasileiro, evitando termos rebuscados, construções desnecessariamente complexas e estrangeirismos quando houver uma alternativa em português que expresse a mesma ideia com clareza.

> Termos técnicos consolidados na área de tecnologia podem ser utilizados quando sua tradução dificultar a compreensão ou criar ambiguidade.

O objetivo não é traduzir tudo de forma artificial.

O objetivo é que **uma pessoa brasileira consiga ler o projeto e entender, tanto quanto possível, o que está sendo feito.**
